# Dora-LeRobot release notes

## Proposed `v0.1.0-alpha`

This release presents Dora-LeRobot as a reference integration for SO-ARM and
Seeed B601 DM/RS robots. It uses Robot HAL for transport/resource ownership,
keeps local action safety in robot adapters, and bridges observations/actions to
LeRobot-compatible datasets and policies.

The release is experimental and requires the relevant physical acceptance
checklist before any hardware is connected. Hardware-free tests do not imply
safety certification or successful qualification on every robot.
