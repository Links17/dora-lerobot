# Security

Do not report security issues in public issues. Send a concise description,
reproduction steps and affected commit to the repository maintainers through
the private security channel configured for this project.

Do not include credentials, private hardware identifiers, customer data,
datasets or unredacted logs. Physical-safety incidents should also be stopped
locally with the robot emergency-stop procedure before collecting diagnostics.

This project is alpha software and is not a safety-certified controller.
Remote policy or cloud connectivity must never be treated as a safety boundary.
